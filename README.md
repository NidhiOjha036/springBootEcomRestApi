SpringEcom – E-commerce Product Management REST API

Technologies: Java 21, Spring Boot 4, Spring Data JPA, Hibernate, MySQL, Maven, Lombok

Developed a RESTful backend application using Spring Boot to manage e-commerce product information.

Implemented CRUD operations to add, retrieve, update, and delete products using Spring Data JPA.

Integrated MySQL database using Hibernate ORM for persistent data storage.

Implemented product search functionality using custom JPQL queries.

Added image upload and retrieval functionality using Spring MultipartFile.

Followed a layered architecture using Controller, Service, Repository, and Entity components.
